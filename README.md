# E-Commerce Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing **E-Commerce sales data** using Python, Pandas, SQL, Excel, and data visualization techniques.

The goal of this project is to clean, analyze, and visualize sales data to identify important business insights related to **sales, profit, products, categories, regions, customers, and segments**.

## 🎯 Objectives

* Clean and preprocess the Superstore dataset
* Analyze overall sales and profit performance
* Calculate important business KPIs
* Identify top-performing products
* Identify loss-making products
* Analyze region-wise sales and profit
* Analyze category and segment performance
* Analyze monthly sales trends
* Create meaningful charts and visualizations

## 🛠️ Tools & Technologies

## 📂 Dataset

The project uses the **Superstore dataset**, containing information about orders, customers, products, sales, profit, discounts, regions, categories, and other business-related fields.

## 🧹 Data Cleaning

The following data-cleaning steps were performed:

* Converted `Order Date` and `Ship Date` into datetime format
* Handled missing values
* Removed unnecessary `$` signs and commas from numerical fields
* Standardized text values
* Checked and corrected data types
* Prepared the dataset for analysis

## 💡 Key Insights

* **Technology** generated the highest sales among the three major categories.
* **West Region** recorded the highest sales and profit.
* **Consumer Segment** contributed the highest overall sales.
* The overall business generated a **12.47% profit margin**.
* Product-level analysis helps identify both high-performing and loss-making products.
